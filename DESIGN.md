# FRX Construction — Style Reference

Brand of https://frxconstruction.ca. This portal is an FRX Construction product.

## Palette (do not invent others)

| Token | Hex | Use |
|---|---|---|
| Jaune brûlé | `#FBAA19` | Primary actions, key accents, active nav, brand mark |
| Noir | `#000000` | Sidebar, headings, primary text, dark surfaces |
| Concrete | `#51514E` | Muted text, secondary labels, supporting chrome |
| Gris pâle | `#D1D3D4` | Borders, input rings, hairlines, pale fills |

Surfaces: warm off-white `#F4F4F3` background, pure white cards. Dark mode is near-black with the same yellow accent.

## Logos (in `/public/brand`)

- Horizontal wordmark: `/brand/logo-horizontal.jpg` — login and marketing surfaces only (JPG has a white field).
- Yellow icon: `/brand/logo-icon.png` — dark sidebar, inverted lockups.
- Black icon: `/brand/logo-icon-black.png` — light surfaces.
- Vertical invert: `/brand/logo-vertical-invert.png` — spare / print.

## Type

- Display / headings: **Barlow Condensed**, uppercase, tight tracking.
- UI / body: **Barlow**.
- Two weights on a screen. Tabular numerals on money and KPIs.

## Do

- Lead with black + pale gray. Yellow is the seasoning — primary buttons, focus rings, active states.
- Keep corners tight (`0.375rem`). Construction, not consumer-saas softness.
- Use the FRX mark, never a generic hard-hat as the brand.

## Don't

- Don't use SoluTI, Forge, teal, or navy. This is not a SoluTI product.
- Don't put yellow on yellow, or yellow text on pale gray (fails contrast).
- Don't stretch the logo or recolor the F-mark.
